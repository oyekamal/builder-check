# Builder Check
Short illustrated assessment for the Full-Stack Builder role. Static page, no build step.
- `index.html` is the quiz. Add `#review` to the URL for the reviewer page.
- `Code.gs` is the storage backend (Google Apps Script plus a Google spreadsheet). Set `API` in `index.html` to its web app URL.
- Without `API`, candidates get a copy-paste code instead.
